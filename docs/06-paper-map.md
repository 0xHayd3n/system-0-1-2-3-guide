## Page convention

Every page link below uses the **one-based PDF page**, the position shown by a PDF viewer. The file has **41 PDF pages**. PDF page 1 is the title and author page; PDF page 2 contains the abstract and keywords. The main text restarts its printed numbering: **PDF page 3 = printed page 1**, and from there **PDF page = printed page + 2** through PDF page 41 = printed page 39. The abstract page's printed number should therefore not be used to infer a uniform offset for the front matter.

A span includes pages shared with adjacent sections. An anchor opens the first relevant PDF page; read through the listed end page. Source page numbers inside quotations or bibliographic entries may instead refer to books or other papers and must not be treated as this PDF's page numbers.

## Efficient reading passes

1. **Orientation:** PDF pages 2–5, Figure 3, Table 1, and the conclusion. State the proposal before evaluating it.
2. **Mechanisms:** §§2.1–2.3 and §3.2. Keep prior demonstrations separate from claims about the complete four-system architecture.
3. **Philosophical structure:** §2.4, Figure 5 and all of §4. Distinguish operating dynamics from the history that formed their constraints.
4. **Critical assessment:** all of §5 and the validation agenda in §6. Separate cited evidence, testable predictions and speculative extensions.

For any referenced work, the bibliography is a discovery route. This companion's detailed source coverage is limited to the pinned v3 paper; it does not claim to have independently audited every study the paper cites.
